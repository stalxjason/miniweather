## 规格

- 128×128 PNG，RGBA 透明通道，与现有图标同规格
- 图形净区约 108px（留白 ~8%），选中/未选中同形状，仅颜色不同
- 颜色取自 `app.json`：未选中 `#8E8E93`（`tabBar.color`），选中 `#1677FF`
  （`tabBar.selectedColor`），与 tab 文字色一致
- 体积 4.2–6.0 KB（旧图标 24 KB，微信小程序图标上限 40 KB）

## 相对现有图标的改动

1. **选中/未选中形状一致**。旧图标选中态会丢失一个元素：天气未选中是
   「太阳+云」、选中只剩「云」；潮汐未选中是「波浪+水滴」、选中只剩「波浪」。
   新版四张图标形状完全一致，只改颜色。
2. **补齐缺失元素**：天气选中态补回太阳；潮汐选中态补回水滴。
3. **云的形态**：旧云偏扁圆、边缘有机；新版为「三鼓包 + 圆角平底」的几何云，
   太阳右下两根光线真正被云体挡住，构成「云后出日」的层次。
4. **抗锯齿**：旧图标 alpha 只有 0/255 两个值（硬边，放大可见锯齿）；
   新版为 6 倍超采样 + LANCZOS 降采样，alpha 有 200+ 级灰阶。
5. **体量**：旧图标图形占满 86% 画幅且硬边，视觉偏重；新版净区约 84% 并带
   柔和边缘，与 tabBar 文字更协调。

## 图形构成

- **天气**：太阳（圆盘 r7.2 + 8 根圆头光线，r10.8→r14.2，粗 3.4）在左上，
  云在右下；云 = 圆角平底 + 半径 9/12/8 三个鼓包。
- **潮汐**：水滴（顶点 + 两条与球面相切的斜线 + 球体 r5.6，切线连接无折角）
  在上，波浪在下；波浪 = 1.5 周期正弦、端点收尖、中部最粗 11.2 的渐变带。

## 确认后代入方式

文件名与 `app.json` 中 `tabBar.list[].iconPath` / `selectedIconPath` 的引用
一致，因此直接覆盖即可，无需改配置：

```bash
cp design/tabbar-v2/icon-*.png miniprogram/images/
```

如需 81×81（微信官方建议尺寸）版本，把 `gen_icons.py` 里的 `SIZE` 改为 81 重跑。
